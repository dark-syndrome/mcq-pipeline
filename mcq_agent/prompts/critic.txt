EVALUATION PROCEDURE:

Step 1 — Independent answering:
Before looking at which option is marked correct, read the question and the options. Based ONLY on the source content, determine which option(s) you would choose. State your reasoning.

Step 2 — Comparison:
Compare your answer with the marked correct answer. If they differ, the question is likely flawed.

Step 3 — Criterion-by-criterion check:

a) **Source grounding**: Is the marked correct answer explicitly supported by the source? Quote the supporting passage. If you cannot find supporting text, mark this FAIL.

b) **Uniqueness / ordering correctness**:
   - For single_correct: Is exactly one option unambiguously correct? Could a knowledgeable person reasonably argue for another option? If yes, mark FAIL.
   - For ordering: The question uses a two-part structure. The numbered steps live in the `ordering_statements` field AND must be visible in the question stem; each option is a sequence string of those step numbers (e.g. "3 → 1 → 4 → 2"). Verify ALL of the following or mark FAIL:
       * `ordering_statements` is present and non-empty, and the numbered steps appear in the question text. If the stem only says "the following steps are listed out of order" but the actual numbered steps are MISSING, the question is incomplete and unanswerable — mark FAIL on self-containment.
       * Exactly one option has is_correct=true (the correct sequence); the rest have is_correct=false with a distractor_rationale.
       * Every option's sequence references only valid step numbers (1..N where N is the number of statements) and lists all of them once.
       * The single correct sequence is verifiable from the source. If the correct order is ambiguous or not derivable from the source, mark FAIL.
       * Note: the legacy `correct_order` field must be null — correctness is encoded via is_correct on the option.
   - For multiple_correct: At least TWO but not all options are correct. Each correct option must be independently verifiable from the source. If only one option is correct, the type is mislabelled — mark FAIL.

c) **Distractor plausibility**: Are the wrong options plausible to someone with partial knowledge? Or are any of them absurd, off-topic, or obviously wrong? If any distractor is implausible, mark FAIL.

d) **Difficulty match**: Does the question's cognitive demand match the claimed difficulty level?
   - EASY = recall/comprehension only
   - MEDIUM = application to scenario
   - HARD = analysis/comparison
   - EXPERT = evaluation/judgment
   If mismatch, mark FAIL.

e) **On-topic**: Does the question test content actually present in the source? Or does it go off-topic or require outside knowledge? If outside source, mark FAIL.

f) **Clarity**: Is the question wording clear, unambiguous, and free of double negatives or trick phrasing? If not, mark FAIL.

g) **Self-containment**: Can the question be answered without reference to other questions or external context? If not, mark FAIL.

h) **Stem quality**: Does the question require the learner to *do something* with the knowledge (apply, analyze, evaluate) rather than just recall a definition?
   - EASY: recall is acceptable.
   - MEDIUM and above: a pure definition question FAILS this criterion. The stem must place the concept in a context that requires use, not just recognition.
   If the stem is a definition lookup at medium/hard/expert difficulty, mark FAIL and suggest a scenario reframe.

i) **Stem economy**: Is the stem concise? Does every sentence in the scenario contribute to making the decision unambiguous?
   - FAIL if the stem contains context details that are not needed to answer the question (stem inflation).
   - Target: a student should not have to wade through more than 2–3 sentences of scenario before reaching the actual question.

j) **Option length parity**: Is the correct answer visibly longer than the distractors?
   - Compute approximate word counts. If the correct answer is more than 30% longer than the median distractor word count, mark FAIL.
   - Suggest either trimming the correct answer or expanding the distractors to restore parity.

k) **Source-phrase independence**: Does the correct answer reproduce 5 or more consecutive words from the source_excerpt?
   - If yes, mark FAIL. The correct answer must paraphrase; it must not be answerable by phrase-matching against the source.

Step 4 — Verdict:
- Mark `passes: true` ONLY if ALL criteria pass.
- If any criterion fails, mark `passes: false` and list specific issues.
- If the question is close to passing, provide a `suggested_fix` describing what would need to change.

Return your evaluation as JSON matching the CritiqueResult schema.

Be strict. It is better to reject a mediocre question than to let it through.
